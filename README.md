# FireBlind
Архівний тренажер моніторингу диму. Відкрийте index.html із розпакованої теки. Оберіть добу, станцію та тривалість збою. Порівняйте рішення зі старим виміром, а тоді відкрийте фактичне значення. Для прикладу помилки оберіть 1 липня, станцію 36-081-0124 та три доби. Демонстрація працює офлайн.

## Відтворення
Потрібен Node.js (перевірено на 24), зовнішніх пакетів немає. У теці проєкту виконайте:
```
node experiment.cjs
node experiment.cjs --2024
node test.cjs
```
Перший запуск створює summary.json та replay.js, другий — summary2024.json. model.js містить правила. test.cjs перевіряє межі порога, календар, пропуски, унікальність записів і походження входів кожного прикладу демонстрації.

## Дизайн експерименту
Приховуємо поточний вимір станції та всі локальні значення після дня t−L. L = 1, 3, 7. Просте правило повторює значення у t−L. Якщо його теж немає, обидва методи утримуються. Для кожного L обчислюємо за січень–травень 2023 міждобові різниці y(t)−y(t−L) на тій самій станції. Запас q — невід’ємна частина порядкової статистики рангу ceil(0.90(n+1)), об’єднаної по станціях. Верхня оцінка = старий вимір + q. Часові та просторові залежності виключають обіцянку 90% покриття.

Старий вимір ≥35 позначає можливе перевищення. Для нижчого значення повний метод дозволяє повідомлення «нижче порога», коли верхня оцінка <35, є хоча б одна інша станція з даними за поточну добу та всі такі станції показали <35. Інакше відповідь невизначена. Оцінка доступна після надходження добових агрегатів. Це імітація недоступності, без перевірки реальних журналів відмов. Поріг експериментальний. Джерело частинок за концентрацією визначити неможливо. Дим 6–8 червня окремо задокументований [CDC](https://www.cdc.gov/mmwr/volumes/72/wr/mm7234a6.htm).

## Результати
У червні–грудні 2023 є 897 станція-діб. У таблиці порівнюються лише пари з наявним виміром у t−L. «Хибно низько» означає відповідь «нижче порога» при факті ≥35. Невизначеність не зараховується як виявлення.

|Діб|Пар|Факт ≥35|Хибно низько, базовий → повний|Невизначено, повний|Хибні попередження, обидва|
|---:|---:|---:|---:|---:|---:|
|1|877|11|4 → 0|14|4|
|3|861|11|11 → 1|21|11|
|7|843|11|11 → 1|21|11|

Ще 20, 36 та 54 випадки відповідно мали відсутню локальну історію й отримали невизначений статус в обох методах. Для трьох діб із 11 перевищень повний метод дав 10 невизначених відповідей, одну хибно низьку та жодного прямого попередження. 1 липня в Квінзі сусідня станція показала 33,46, прихована — 38,58. Усі 11 перевищень зосереджені на двох станціях і шести датах; три сценарії повторно використовують ці виміри.

Перша версія із самим запасом q не усунула жодного хибно низького повідомлення. Перевірку сусідів додано після перегляду результатів 2023. Окреме правило лише із сусідами дало ті самі числа помилок і на десять менше невизначених відповідей для кожного L. Отже, користь додаткового запасу тут не продемонстрована. Для L=3 верхню оцінку перевищено у 145/861 пар (16,8%).

Незалежний наступний період — 2024, без зміни параметрів. Для L=3 серед 2139 придатних пар не було перевищень. Повний метод утримався 5 разів, базовий — 0. Ще 20 випадків без історії. Цей період перевіряє ціну обережності, але не чутливість під час пожеж. Для подальшої перевірки потрібен інший димовий епізод, вибраний до обчислення результатів.

## Наукові аналоги
Імовірнісне відновлення пропущених спостережень PM2.5 вже досліджували [Probabilistic predictive PCA](https://pmc.ncbi.nlm.nih.gov/articles/PMC7313548/). Оцінку невизначеності PM2.5 саме за зміни умов під час пожеж вивчали у [Spatial-Aware Uncertainty Quantification](https://www.mdpi.com/2073-4433/17/7/692). FireBlind демонструє вузьке інженерне рішення: відтворюваний показ конкретного рішення оператора при прихованому вимірі, з підрахунком помилок та утримань. Претензії на першість алгоритму немає. Огляд цільовий, не систематичний.
